# Third-party and reference sources

The first HashWX/HashX exhibit is derived from and compared against these upstream projects:

- `tevador/hashwx`, canonical revision `74b567a31276a4c5d7cb232a5b7639467f49f961`
- `tevador/hashx`, canonical revision `08babdf4f41b0b8991d1fa94914c7c6902de0cb6`
- `codeandsolder/hashwx-rs`, initial museum reference revision `44d5543273329843bf61268c8b0756798c86fb8e`

Recovered historical experiments under `archive/hashwx-fixed-v1/` were written while developing the HashWX implementation and are retained so benchmark conclusions remain auditable. Their generated instruction stream is normalized as `workloads/hashwx-fixed-v1/program.json`.
